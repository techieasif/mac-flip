Mac Flip

Dot-matrix desktop widgets for the Mac, set like a split-flap board you can read from across the room.

On the desktop, a changed cell fades. WidgetKit cannot run its own animation loop, so the Mac uses an opacity content transition when the next minute arrives. This page turns the cell in 3D, the same way the browser preview does.

Six widgets

Each one is a WidgetKit board. Sizes match the desktop grid: 164×164, 344×164, 344×344, and 724×344 points.

Eight themes

Midnight, Obsidian, Amber, and Phosphor glow. Paper, Matcha, Lemon, and Sky stay flat. One theme can cover every board, or a board can keep its own. Edit Widget can override it again.

Private

No account, no analytics, and no license check. The privacy manifests declare no tracking and no collected data. Settings are a JSON blob in the App Group user defaults, on this Mac.

68 cities

Plus This Mac, which follows the computer’s time zone. The world board shows the cities you list, in order. Medium shows the first four as codes, large the first eight by name, extra large the first seven by name.

Quiet on battery

A widget publishes one timeline entry per minute for the next hour, then sleeps. It does not tick every second. The desktop timeline reloads when you change a setting.

On the desktop

Build and run Mac Flip once, then leave the boards on the desktop.

  1. Open Mac Flip and set the cities, the countdown, the message, and the theme.
  2. Right-click an empty spot on the desktop and choose Edit Widgets.
  3. Search for Mac Flip. Drag World Board, Clock, Day, Progress, Countdown, or Sign onto the desktop at the size you want.
  4. Click a widget to open Mac Flip on that board. To give one widget its own city, period, message, or theme, right-click it and choose Edit Widget. Leave a field on “Match the App” to keep following the companion app.

Build from source

There is no download store and no price. You need Xcode 15 or later on macOS 14 or later, and XcodeGen. The Xcode project is generated and gitignored. project.yml is the definition.

brew install xcodegen
xcodegen generate
open MacFlip.xcodeproj

Set your Development Team on both the MacFlip and MacFlipWidgets targets. Both need the App Group group.dev.macflip.shared. Then run the MacFlip scheme. The widget extension is embedded in the app.
